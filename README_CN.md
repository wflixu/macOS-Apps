#   macOS-Apps

精选 macOS 开源应用

[English](README.md)


## 开发工具

- [Visual Studio Code](https://code.visualstudio.com) - 轻量但强大的源代码编辑器，可在 macOS 上运行。

- [Terminal Workspace](https://github.com/EvanAI0331/terminal-workspace) - 多项目终端工作区，用于管理 macOS 上的本地开发环境。

- [Ghostty](https://github.com/ghostty-org/ghostty) ![native] 快速、功能丰富的 macOS 终端模拟器，使用 Zig 构建。


## 效率工具

- [Maccy](https://github.com/p0deje/Maccy) ![native] macOS 剪贴板管理工具。

- [RClick](https://github.com/wflixu/RClick) ![native] Finder 扩展，用于自定义右键菜单。

- [AIME](https://github.com/wflixu/AIME) ![native] 根据不同应用自动切换输入法。

- [SwitchKey](https://github.com/itsuhane/SwitchKey) ![native] 自动激活正确的输入源。

- [Loop](https://github.com/MrKai77/Loop) ![native] - 优雅的窗口管理工具。

- [Ice](https://github.com/jordanbaird/Ice) ![native] - 强大的 macOS 菜单栏管理器

- [FinderSyncer](https://github.com/wflixu/FinderSyncer) ![native] - 适用于 macOS Sequoia 15 的 Finder 同步扩展

## 视频与图像

- [IINA](https://github.com/iina/iina)  ![native]  现代 macOS 视频播放器。

- [LiveCam](https://github.com/wflixu/LiveCam)  录屏时显示你的虚拟形象。

- [Gifski](https://github.com/sindresorhus/Gifski)  ![native]  在 Mac 上将视频转换为高质量 GIF

- [QuickRecorder](https://github.com/lihaoyun6/QuickRecorder) ![native] 基于 ScreenCapture Kit 的轻量级 macOS 屏幕录制工具

- [iMonet](https://github.com/wflixu/Monet) ![native] 为鼠标和触控板用户优化的 macOS 图片查看器，使用 SwiftUI 构建。

- [Cap](https://github.com/CapSoftware/Cap)  开源 Loom 替代品。轻松、即时的屏幕分享。

- [capcap](https://github.com/realskyrin/capcap) ![native] 轻量级 macOS 截图工具，双击 ⌘ 即可截取任意区域，常驻菜单栏。

## 系统工具

- [Dusty](https://github.com/yagcioglutoprak/dusty) ![native] - 菜单栏磁盘清理工具，采用仅允许列表的删除引擎，删除前会显示每个路径

- [Pearcleaner](https://github.com/alienator88/Pearcleaner) 免费、源码可用、公平代码许可的 Mac 应用清理工具
